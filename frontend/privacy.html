Privatlivspolitik

Sidst opdateret: 6. maj 2026

Denne politik beskriver hvilke personoplysninger vi indsamler, hvorfor vi indsamler dem, og hvilke rettigheder du har som bruger af chat-tjenesten på chat.apps.gihc.online.

Hvad gemmes

DataFormål
BrugernavnIdentifikation i chat
Email-adresseVerifikation af konto ved oprettelse
Adgangskode (Argon2id-hash)Autentificering — selve adgangskoden gemmes aldrig
BeskederChat-historik i rum og private samtaler
TidsstemplerOprettelsestidspunkt for konto og beskeder

Hvad gemmes ikke

  • IP-adresser logges ikke og gemmes ikke
  • Browserdata, cookies og trackingdata indsamles ikke
  • Data deles ikke med tredjepart undtagen de nødvendige underleverandører nedenfor

Underleverandører

UnderleverandørFormålLokation
Hetzner Online GmbH Serverdrift — PostgreSQL-database og API Helsinki, Finland (EU)
Cloudflare (Turnstile) CAPTCHA-beskyttelse ved registrering USA (behandling af challenge-token — ingen persondata sendes)
Resend Afsendelse af verifikationsemail ved kontooprettelse USA

Dataopbevaring

Konti og beskeder gemmes uden tidsbegrænsning, så længe kontoen er aktiv. Der sker ingen automatisk sletning af inaktive konti. Når du sletter din konto, slettes alle dine oplysninger — brugernavn, email, beskeder og private samtaler — straks og permanent.

Dine rettigheder

Som registreret bruger har du ret til:

  • Indsigt — du kan til enhver tid se alle gemte oplysninger om dig via Kontoindstillinger eller direkte via API-endpointet GET /auth/me.
  • Sletning — du kan slette din konto og alle tilknyttede data permanent via Kontoindstillinger → Slet konto.
  • Dataportabilitet og berigtigelse — kontakt os på nedenstående email.
